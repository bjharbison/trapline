## Blocking risks and change deconfliction

1. **P1 data separation:** enforce same-investigation composite FK ownership for relationship endpoints and evidence/document references *inside #36*; add negative-control SQL migrations and rollback/recovery tests; do not open a rival schema PR or begin mutating APIs against it.
2. **P2 local file privacy and availability:** fix #36 directory/SQLite/WAL permissions and #40 root/shard modes plus FIFO/special-file handling *on their existing PR branches*. Validate race assumptions; document supported local filesystem threat model. Do not wire a document-ingestion endpoint until these fixes and metadata/blob consistency tests pass.
3. **V2 web security gate:** #39 is independently reviewable; Host gate alone is not auth/CSRF. Require Origin/CSRF design before state-changing local APIs. Remote network access stays out of scope. Future URL ingestion must reject private IP/DNS rebinding/unsafe redirect chains with mocked tests, never external scans.
4. **V1 compatibility:** review #41 separately for V1 JSON contract; legacy JSON is not a complete investigation backup. Do not implement import/export or change stable `main` based on presumed V1 semantics.
5. **Governance:** branch API reports all preserved refs `protected: false`. Seek user decision on GitHub rulesets; never interpret the label 'protected' as a configured GitHub guard.
