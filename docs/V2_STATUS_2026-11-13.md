## Current blockers and sequencing

1. **P1: draft PR #36 violates investigation isolation.** Relationship source/target entity FKs and evidence/document FKs only validate record existence, not ownership by the same investigation. QA reproduced cross-case writes in an isolated SQLite test Nov 10. Require database-enforced composite constraints, migration and negative tests, not application-layer filtering alone. Keep #19 document store and #20 mutation APIs behind this integrity gate.
2. **P2: Host port parser bound [#38](https://github.com/bjharbison/trapline/issues/38).** Merged Host gate permits unbounded numeric string conversion. A standalone 5,000-digit Python conversion raises `ValueError`; real HTTP exploitability is unproven. A separate narrow PR should reject before conversion and test 400 responses. This can be developed independently of draft SQL schema.
3. **P2: Recovery and storage permission checks.** PR #36's migration tests do not establish failed-migration recovery or backup restoration; default data directory creation does not tighten pre-existing directory permissions. Review before trusting sensitive local storage.
4. **Security boundary for future mutation APIs:** Host and CORS checks are not authentication or CSRF controls; document Origin/CSRF, loopback exposure, file validation, size and resource limits before new endpoints.
