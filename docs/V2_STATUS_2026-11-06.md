## Security and dependency gates

1. **Before stateful APIs:** Complete #34 Host header / DNS-rebinding guard with validated IPv4/IPv6 loopback behavior, negative tests and actual CI; assess CSRF/auth assumptions for localhost mutating endpoints. The branch is not merged, and prior QA flagged an IPv6 Starlette compatibility issue.
2. **Before file ingestion:** Specify max request/document sizes, safe storage paths, type/content checks, PDF resource bounds, checksum and cleanup behavior, and tests against traversal/corruption. No upload endpoint yet exists to test.
3. **Before SQL release:** Ensure SQLite foreign keys, transaction boundaries, Alembic migration forward tests and recovery/backup plan; PostgreSQL portability is a design target, not verified support.
4. **Before provider/URL features:** No automatic outbound calls, opt-in cloud egress and credential redaction; SSRF, DNS rebinding, redirects and response caps for URL ingestion.
5. **Before V2.0 release:** Synthetic two-document persistence scenario, backup/restore, import/export parity, offline egress and V1 browser regression must all pass. Current green CI does **not** prove those later capabilities.
